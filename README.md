# Trabalho de Linguagens Formais e Autômatos
Para utilização, instale o `npm` e rode os comandos:

1. `npm install` – instala as dependências.
2. `npm run dev` – inicia um servidor de desenvolvimento utilizando [Vite](https://vitejs.dev/) e observa os arquivos SASS.

Para gerar o CSS apenas uma vez (sem servidor) utilize `npm run build`.

Alterações de código devem ser feitas na pasta `app`.
